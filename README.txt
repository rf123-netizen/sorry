BUSHRA SORRY WEBSITE
=====================

Files:
- index.html
- style.css
- script.js

How to run:
1. Keep all three files in the same folder.
2. Double-click index.html, or open it with Chrome/Edge.
3. It works as a static website; no server is required.

Customize:
- Edit the text in index.html.
- Change colors/fonts in style.css.
- Change the final responses and interactions in script.js.

The music button creates a small browser melody with Web Audio, so no copyrighted audio file is bundled.
